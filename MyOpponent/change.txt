Match Setup and Leagues
The Match Setup Modal allows for detailed configuration before starting a match:

Standard Setup: Fields for player names and the "Race To" target number.

League Options: Checkboxes to activate specific league rules and handicaps.

Bar 8 Champions League: Includes a dropdown to select specific pre-defined matches (e.g., Alastair Key vs. Freddie Russell).

Division 1 Singles League (Red): Offers its own dropdown for league-specific matches (e.g., Freddie Russell vs. John Croft).

Step-by-Step Instructions
Go to the repository: https://github.com/mobileweb4u/happy4u-score.

Click the Add file button and select Create new file.

The Slash Trick: In the box for the file name, type:

MyOpponent/

As soon as you type the forward slash (/), GitHub will turn "MyOpponent" into a folder.

Now, you must name the file inside that folder. You can name it .gitkeep (this is a common placeholder used to keep folders from being deleted while they are empty).

Your full path should look like: MyOpponent/.gitkeep

Scroll down to Commit changes, write a message like "Create MyOpponent folder," and click Commit changes.
