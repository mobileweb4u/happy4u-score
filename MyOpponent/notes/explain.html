System Explanation

Documentation of the HAPPY4U Scoreboard Ecosystem

index.html Core UI
The main application shell. Handles the visual layout, mobile-app optimizations, modal structures (Match Setup, Summary, Settings), and the sponsor rotation system.
Interface
script.js Logic Engine
The primary brain of the scoreboard. Manages the gameState, handles real-time scoring, persists data via LocalStorage, and synchronizes the UI with game events.
JavaScript
champions.js League Module
Dedicated engine for the Bar 8 Champions League. Automates "Frames Start" handicap rules and generates high-fidelity, formatted match reports for the summary view.
Rules & Reporting
menu.js Navigation
The master controller for settings. Manages league mode selection (Bar 8 vs. Singles), enforces rule exclusivity, and bridges the transition from setup to the 'Lag' phase.
Menu Controller
practice.js Practice Module
Logic for "Practice Night Mode." Provides a partner database, automates name entry via dropdowns, and defaults the game to a "Race To 5" format.
Utility
archive.html Data Management
The Archive Center. Allows users to export live match data as .json files and upload historical records to view stats like Dishes and Final Scores.
Storage
MyOpponent.html Schedule Utility
A specialized calculator for Frederick Russell [+3]. Maps out specific league opponents and calculates the "Real Race" needed to win based on specific handicaps.
Calculator
player-list.html Reference
The official "Pot 2" player list. An administrative reference used to classify players into tiers (Pot 1, Pot 2, Champ) and verify base handicap values.
Data Table
